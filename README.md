## 🩺 AarogyaAI – AI-Powered Personal Wellness Assistant

🔗 **Live Demo:** https://arogya9.netlify.app/

🌱 **AarogyaAI** is an AI-powered wellness platform designed to help users monitor and improve their daily lifestyle habits through **personalized insights, wellness scoring, recommendations, and an interactive AI assistant**.

### ✨ Key Features

🤖 **AI Wellness Assistant**
• Interactive chat assistant for general wellness-related questions
• Provides guidance on **sleep, exercise, hydration, nutrition, and stress**
• Supports both AI-powered responses and an offline rule-based fallback

📊 **Wellness Score**
• Calculates an overall **0–100 wellness score**
• Tracks individual scores for:

* 😴 Sleep
* 🏃 Exercise
* 💧 Hydration
* 🥗 Nutrition
* 🧘 Stress

🎯 **Personalized Recommendations**
• Identifies the user's strongest and weakest wellness areas
• Generates prioritized recommendations based on daily habits
• Provides a simple **plan for tomorrow** based on current wellness performance

📅 **Daily Wellness Tracking**
• Record daily health and lifestyle information
• Monitor wellness habits over time
• View progress through a user-friendly dashboard

⏰ **Smart Reminders**
• Set reminders to support healthy daily routines
• Helps users stay consistent with wellness goals

📈 **Reports & Insights**
• Generates wellness reports from recorded data
• Helps users understand their daily performance and areas that need improvement

🔐 **Secure User Authentication**
• User registration and login
• JWT-based authentication
• Personalized profile and wellness data

🚨 **Safety-First AI**
• Detects potential red-flag messages before generating normal responses
• Provides appropriate guidance to seek professional medical help when necessary
• Designed as a **wellness assistant, not a medical diagnosis system**
